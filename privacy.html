隐私政策

生效日期：2026-09-09

1. 引言

1.1 本隐私政策适用于 Minecraft 网易版存档解密工具（以下简称“本工具”），旨在向您说明本工具如何处理与您相关的信息。

1.2 本工具的核心设计原则是：所有解密操作均在浏览器本地完成，存档文件不会上传至任何服务器。本政策将具体说明这一原则如何落实。

1.3 使用本工具即表示您已阅读并理解本隐私政策。

2. 我们收集的信息

2.1 存档文件：本工具不会收集、上传、存储或查看您的存档文件。所有文件处理均在您的浏览器本地进行。

2.2 个人信息：本工具不要求您提供任何个人身份信息（如姓名、邮箱、电话号码等），也不提供账号注册或登录功能。

2.3 解密结果：解密生成的文件同样仅存在于您的本地设备，由您自行下载或覆盖原文件，本工具无法获取。

3. 本地存储与 Cookie

3.1 本工具可能使用 localStorage 和 Cookie 记录以下偏好信息：

· 文件夹选择功能是否可用（用于避免重复检测）；

· 版本更新提醒的忽略状态及具体版本号。

3.2 上述信息仅存储于您的浏览器本地，不涉及任何个人身份识别，也不会被上传或与第三方共享。

3.3 您可以通过浏览器设置清除这些本地存储和 Cookie，不影响本工具的正常使用。

4. 版本检测请求

4.1 本工具会向项目服务器请求公开的 version.json 文件，用于检查是否有新版本可用。

4.2 该请求不携带任何个人数据、存档内容或浏览历史，仅用于获取版本信息。

4.3 请求过程中，服务器端可能记录基础的访问日志（见第 5 条）。

5. 服务器日志

5.1 托管本工具及 version.json 的服务器可能会自动记录常规的访问日志，包括但不限于：

· IP 地址；

· 访问时间；

· 浏览器类型（User-Agent）；

· 请求的具体路径。

5.2 这些日志仅用于基本的运行维护、故障排查和安全防护，不会用于识别个人身份，也不会与任何第三方分享。

5.3 日志的保存周期由服务器托管方决定，项目作者不会主动收集或分析这些日志。

6. 第三方服务

6.1 本工具使用了以下第三方资源：

· JSZip：通过 CDN 加载，用于在浏览器本地处理 ZIP 文件；

· Google Fonts：用于加载页面字体；

· shields.io：用于显示许可证徽章。

6.2 加载这些资源时，您的浏览器可能会向对应的第三方服务器发起请求，第三方可能记录其自己的访问日志。项目作者不对第三方服务的数据处理行为负责。

6.3 如您不希望与这些第三方服务器通信，可以选择离线使用本工具（直接打开本地 HTML 文件），但部分功能可能受限。

7. 数据安全

7.1 由于存档文件不会离开您的浏览器，本工具从根本上降低了数据泄露的风险。

7.2 尽管如此，请自行妥善保管您的存档文件和已解密的文件。本工具无法保护您的本地设备免受恶意软件、木马或未授权访问的威胁。

8. 儿童隐私

8.1 本工具不收集任何个人身份信息，因此也不涉及儿童隐私数据的收集。

8.2 如您是未成年人，请在监护人指导下使用本工具。

9. 政策变更

9.1 本隐私政策可能随时更新，更新后将在本页面公示。

9.2 重大变更时，项目作者可能通过版本更新提醒等方式通知使用者。

9.3 继续使用本工具即表示您接受修改后的隐私政策。

10. 联系我们

10.1 如对本隐私政策有任何疑问、意见或建议，请通过项目 GitHub Issues 页面与我们取得联系。

本隐私政策最终解释权归项目作者所有。
