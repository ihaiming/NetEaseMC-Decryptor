1. Introduction

1.1 This Privacy Policy applies to the Minecraft NetEase Edition Save Decryption Tool (hereinafter referred to as "this Tool") and is intended to explain how this Tool handles information related to you.

1.2 The core design principle of this Tool is: all decryption operations are performed locally in your browser, and save files are never uploaded to any server. This Policy explains how this principle is implemented.

1.3 By using this Tool, you acknowledge that you have read and understood this Privacy Policy.

2. Information We Collect

2.1 Save Files: This Tool does not collect, upload, store, or view your save files. All file processing is performed locally in your browser.

2.2 Personal Information: This Tool does not require you to provide any personally identifiable information (such as name, email address, phone number, etc.), nor does it offer account registration or login functions.

2.3 Decryption Results: Decrypted files also exist only on your local device. You download them yourself or overwrite the original files. This Tool cannot access them.

3. Local Storage and Cookies

3.1 This Tool may use localStorage and Cookies to record the following preference information:

· Whether the folder selection function is available (to avoid repeated detection);

· The ignore status and specific version number of update reminders.

3.2 The above information is stored only in your browser locally, does not involve any personal identification, and will not be uploaded or shared with third parties.

3.3 You can clear this local storage and these cookies through your browser settings without affecting the normal use of this Tool.

4. Version Check Requests

4.1 This Tool requests the public version.json file from the project server to check whether a new version is available.

4.2 This request does not carry any personal data, save content, or browsing history. It is used solely to obtain version information.

4.3 During the request, the server may record basic access logs (see Section 5).

5. Server Logs

5.1 The server hosting this Tool and version.json may automatically record routine access logs, including but not limited to:

· IP address;

· Access time;

· Browser type (User-Agent);

· The specific requested path.

5.2 These logs are used only for basic operation and maintenance, troubleshooting, and security protection. They are not used to identify individuals and are not shared with any third party.

5.3 The retention period of logs is determined by the server hosting provider. The Project Author does not actively collect or analyze these logs.

6. Third-Party Services

6.1 This Tool uses the following third-party resources:

· JSZip: loaded via CDN, used to process ZIP files locally in the browser;

· Google Fonts: used to load page fonts;

· shields.io: used to display the license badge.

6.2 When loading these resources, your browser may send requests to the corresponding third-party servers, and those third parties may record their own access logs. The Project Author is not responsible for the data handling practices of third-party services.

6.3 If you do not wish to communicate with these third-party servers, you may choose to use this Tool offline (by opening the local HTML file directly), though some features may be limited.

7. Data Security

7.1 Because save files never leave your browser, this Tool fundamentally reduces the risk of data leakage.

7.2 Nevertheless, please take good care of your save files and decrypted files. This Tool cannot protect your local device from malware, trojans, or unauthorized access.

8. Children's Privacy

8.1 This Tool does not collect any personally identifiable information, and therefore does not involve the collection of children's privacy data.

8.2 If you are a minor, please use this Tool under the guidance of a guardian.

9.2 In the event of significant changes, the Project Author may notify users through version update reminders or other means.

9.3 Continued use of this Tool constitutes acceptance of the modified Privacy Policy.
